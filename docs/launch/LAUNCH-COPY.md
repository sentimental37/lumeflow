## One-line description

LumeFlow is a visual builder and framework-neutral rendering library for polished,
source-controlled architecture diagrams.

## Short description

Create a diagram by drag and drop, keep it as portable JSON, and render the same
source in React, Next.js, Angular, or any web app. LumeFlow includes deterministic
layout and routing, themes, SVG and raster export, a CLI, and an agent authoring skill.

**Opening**

```text
I built LumeFlow because architecture diagrams often force a choice between polished
visuals and maintainable source. It stores the diagram as readable JSON, provides a
no-signup drag-and-drop builder, and renders the same source through a framework-neutral
core plus React, Next.js, Angular, and Web Component adapters.

The difficult parts were deterministic layout, keeping connectors clean as nodes move,
and making visual editing coexist with source control. The builder also exposes explicit
connection controls, so creating and removing links does not depend on discovering a
small canvas handle.

Try the builder: https://sentimental37.github.io/lumeflow-showcase/builder/
Source: https://github.com/sentimental37/lumeflow

It is pre-1.0. I would especially value feedback on the JSON model, routing quality,
and the five-minute framework integration path.
```
