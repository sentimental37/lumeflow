# LumeFlow 0.1.0 — first public source release

LumeFlow makes architecture diagrams visual enough for a presentation and portable
enough for source control. One readable JSON document can be edited in the browser,
rendered across web frameworks, validated in CI, exported, and maintained by an agent.

## Highlights

- **Visual Studio:** drag and drop nodes, connect components explicitly or by handle,
  edit properties and JSON, tune complete themes, recover local drafts, and export.
- **Framework reach:** React 18/19, Next.js 14–16, Angular 17–22, and a Web Component
  for Vue, Svelte, Solid, Lit, Astro, or plain JavaScript.
- **Diagram engine:** deterministic Dagre, grid, lane, and manual layouts with curved,
  smooth-step, orthogonal, or straight routing.
- **Presentation quality:** polished dark and light themes, semantic nodes and edges,
  accessible SVG, motion, pan/zoom, and raster or standalone HTML export.
- **Automation:** CLI validation, inspection, rendering, schema output, Mermaid topology
  migration, and an agent skill for `*.visual-flow.json` source.

## Packages

This release prepares the following public package surface:

- `@lumeflow/core`
- `@lumeflow/react`
- `@lumeflow/angular`
- `@lumeflow/next`
- `@lumeflow/cli`

Do not publish this GitHub release until the five package versions have been verified
on the public npm registry. Until then, use the repository source and live builder.

## Known boundaries

- LumeFlow is pre-1.0 and public APIs may evolve with documented migration notes.
- Mermaid migration imports topology and labels, not Mermaid styling.
- Collaborative storage and real-time multi-user editing are not included.
- The builder stores drafts locally and does not require an account or backend.
