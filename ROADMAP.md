# LumeFlow roadmap

The roadmap describes direction, not contractual delivery dates. Discussion and
evidence from real integrations determine priority.

## Now — reliable 0.1 adoption

- Publish `@lumeflow/core`, `react`, `angular`, `next`, and `cli` to npm.
- Prove the five-minute installation path in clean consumer projects.
- Expand accessibility, keyboard editing, and export coverage.
- Collect real-world examples across application architecture, workflows, data
  flows, sequence narratives, and lifecycle diagrams.

## Next — extensibility

- Document custom node renderers and controlled theme packs.
- Add reusable subflows, diagram composition, and richer port semantics.
- Improve Mermaid topology migration diagnostics.
- Add builder command history and more precise alignment tools.
- Publish maintained Vue and Svelte integration examples.

## Later — collaboration without lock-in

- Optional collaboration adapters with a documented storage contract.
- Comments, review states, and shareable read-only presentations.
- Importers for additional portable diagram formats.
- A plugin model for layout engines, exporters, and domain-specific palettes.

## Principles that will not change

- Portable source remains usable without a hosted LumeFlow account.
- The framework-neutral model and renderer stay independent of React, Angular,
  and Next.js.
- Visual editing and source control remain compatible workflows.
- Exports remain deterministic enough for review, documentation, and CI.
