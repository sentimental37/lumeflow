# Support

- Ask usage and integration questions in [GitHub Discussions](https://github.com/sentimental37/lumeflow/discussions).
- Report reproducible defects with the [bug form](https://github.com/sentimental37/lumeflow/issues/new?template=bug-report.yml).
- Propose product changes with the [feature form](https://github.com/sentimental37/lumeflow/issues/new?template=feature-request.yml).
- Report vulnerabilities privately using [SECURITY.md](SECURITY.md).

Please include the LumeFlow package and version, host framework and version,
browser or Node.js version, and a minimal diagram specification whenever possible.
