# Changelog

All notable changes to LumeFlow are documented here. The project follows
[Semantic Versioning](https://semver.org/spec/v2.0.0.html) while the public API matures.

## [Unreleased]

### Planned

- Public npm publication for the five `@lumeflow/*` packages.
- Additional builder templates and example diagrams.

## [0.1.0] - 2026-08-18

### Added

- Framework-neutral diagram schema, validation, deterministic layout, SVG rendering, themes, motion, and export.
- React 18/19, Next.js 14–16, and Angular 17–22 adapters.
- Standards-based Web Component for Vue, Svelte, Solid, Lit, Astro, and plain JavaScript.
- Visual builder with drag and drop, explicit connection controls, inspectors, theme editing, JSON editing, local recovery, and export.
- CLI validation, inspection, rendering, schema output, and Mermaid topology migration.
- Agent skill for creating and validating `*.visual-flow.json` diagrams.
- Full Angular showcase, capability atlas, API reference, framework recipes, and light/dark presentation.
- Distribution checks for all five public package archives.
